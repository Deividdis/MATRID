# MATRID v1.0

**MATRID (Mechanical Authentication and Transformation Rotor Identity Device)** es un generador de contraseñas interactivo inspirado en el diseño de las máquinas mecánicas de cifrado.

El proyecto combina una interfaz web con elementos visuales de estilo mecánico: rotores, teclado, indicadores luminosos y efectos sonoros.

## Características

- Rotores mecánicos interactivos.
- Avance vertical de los rotores.
- Teclado virtual.
- Compatibilidad con el teclado físico.
- Modo de mayúsculas/minúsculas mediante SHIFT.
- Indicadores luminosos para las teclas.
- Generación de contraseñas.
- Copia de la contraseña al portapapeles.
- Efectos de sonido.
- Fondo de madera.
- Diseño inspirado en maquinaria mecánica.
- Interfaz adaptable a diferentes resoluciones.

## Caracteres utilizados

MATRID utiliza:

- Letras mayúsculas: `A-Z`
- Letras minúsculas: `a-z`
- Números: `0-9`
- Símbolos: `! @ # $ % & * ? + - _ =`
